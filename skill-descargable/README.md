# Skill descargable: crear-pagina-de-venta

Paquete listo para instalar el skill **crear-pagina-de-venta** en otro Claude.

## Contenido

| Archivo | Descripción |
|---|---|
| `crear-pagina-de-venta.zip` | El skill empaquetado, listo para subir a claude.ai (Configuración → Capacidades → Skills) o descomprimir en `~/.claude/skills/` para Claude Code. |
| `crear-pagina-de-venta/` | La misma carpeta del skill sin comprimir, por si prefieres copiarla directamente. |
| `GUIA-skill-crear-pagina-de-venta.pdf` | Guía completa (12 páginas): qué hace el skill, cómo instalarlo en cada versión de Claude, cómo se activa, el flujo de 11 pasos, checklist de calidad, errores comunes y FAQ. |

## Instalación rápida

- **Claude Code:** descomprime el ZIP en `~/.claude/skills/` y abre una sesión nueva.
- **claude.ai:** sube el ZIP tal cual en Configuración → Capacidades → Skills.

Todos los detalles están en el PDF.
