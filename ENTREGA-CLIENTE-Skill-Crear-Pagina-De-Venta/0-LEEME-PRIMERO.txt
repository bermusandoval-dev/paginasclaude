───────────────────────────────────────────────────────────────────
  INSTALACIÓN RÁPIDA (más detalle en el PDF, sección 3)
───────────────────────────────────────────────────────────────────

  ▶ Si usas claude.ai (web o app):
    Configuración → Capacidades → Skills → Subir skill
    → selecciona el ZIP tal cual (sin descomprimir).

  ▶ Si usas Claude Code (terminal o app de escritorio):
    Descomprime el ZIP dentro de la carpeta:  ~/.claude/skills/
    Debe quedar así:  ~/.claude/skills/crear-pagina-de-venta/SKILL.md
    Luego abre una conversación nueva.

───────────────────────────────────────────────────────────────────
  ¿QUÉ HACE ESTE SKILL?
───────────────────────────────────────────────────────────────────

  Le enseña a Claude a armar páginas de venta directa completas
  (sales pages) para productos digitales en Shopify: análisis del
  HTML, copywriting profesional, paletas de color, traducción y
  localización, imágenes de bonos, optimización de velocidad, y
  ensamblaje final con order bump + JSON + pixel, listo para subir.

  Para probarlo tras instalar, escribe en Claude:
  "Arma la página de venta" y pega tu HTML o el brief del producto.
